# RPG de Inventario em Java

## Nome da aplicacao
RPG de Inventario

## Descricao das funcionalidades
- Adicionar item ao inventario
- Listar itens cadastrados
- Atualizar item existente pelo ID
- Remover item pelo ID
- Validacao basica dos dados

## Estrutura
- `app/Main.java`
- `inventario/Inventario.java`
- `itens/Item.java`
- `itens/tipos/Arma.java`
- `itens/tipos/Armadura.java`
- `itens/tipos/Consumivel.java`
